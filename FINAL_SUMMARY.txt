🚀 QUICK START
═══════════════════════════════════════════════════════════════════════

1. DATABASE SETUP:
   psql -U postgres
   CREATE DATABASE QuanLiPhanAnh;
   \c QuanLiPhanAnh
   \i backend/database/schema.sql

2. BACKEND:
   cd backend
   npm install
   npm run dev
   ➜ Server: http://localhost:5000

3. FRONTEND:
   cd frontend
   npm install
   npm run dev
   ➜ App: http://localhost:5173

4. LOGIN:
   Resident: /dashboard
   Admin: /admin/dashboard
